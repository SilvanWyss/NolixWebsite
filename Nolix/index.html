Introduction

Description

 Nolix is a Java library that provides useful features for Java applications. Nolix feels comfortable - not technical.

Advantages
  • Simple to include, simple to use, simple to move
  • Code first, no magic
  • Object-oriented by heart

Inclusion

Gradle

 
implementation 'ch.nolix:nolix:0.0.0'

Maven

 
<dependency>
    <groupId>ch.nolix</groupId>
    <artifactId>nolix</artifactId>
    <version>0.0.0</version>
    <scope>compile</scope>
</dependency>
